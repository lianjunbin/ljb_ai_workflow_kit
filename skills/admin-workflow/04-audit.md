## 迭代修改（选择 N 后）

```
💬 想修改提案？

   方案 A：修改设计方案
   👉 输入: /admin:design --revise

   方案 B：只调整任务
   👉 直接编辑: openspec/changes/.../tasks.md

   方案 C：重新分析业务
   👉 输入: /admin:start

修改完成后，再次运行 /admin:audit 审阅新提案
```

## 参数

| 参数 | 描述 | 默认值 |
|------|------|--------|
| `<proposal-name>` | 提案名称（可选，默认使用最新） | - |
| `--skip-confirm` | 跳过确认直接进入应用 | false |
| `--code-only` | 只显示代码逻辑，跳过影响分析 | false |

## 示例

```bash
# 审阅最新提案
/admin:audit

# 跳过确认（谨慎使用）
/admin:audit --skip-confirm

# 只看代码逻辑
/admin:audit --code-only
```
