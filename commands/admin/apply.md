## 参数

| 简化 | 完整参数 | 描述 |
|------|---------|------|
| `-c` | `--continue` | 从上次暂停的位置继续 |
| `-t 3` | `--task 3` | 从第 3 个任务开始 |
| `-r` | `--rollback-all` | 回滚所有已完成的任务 |
| `-p` | `--parallel` | 并行执行独立任务 |

## 示例

```bash
# 开始执行
/admin:apply

# 从上次暂停位置继续
/admin:apply --continue

# 从 Task 3 开始执行
/admin:apply --task 3

# 并行执行独立任务
/admin:apply --parallel

# 回滚所有已完成的任务
/admin:apply --rollback-all
```

---

## 快捷键说明

| 快捷键 | 功能 |
|--------|------|
| `Y` | 继续执行下一个任务 |
| `S` | 跳过当前任务 |
| `P` | 暂停执行，进入回滚选择 |
| `?` | 显示帮助 |

---

## 常见问题

```
🆘 遇到问题？

Q: 执行到一半想修改提案怎么办？
A: 输入 P 暂停，然后选择要保留哪些任务，
   修改提案后用 /admin:apply --continue 继续

Q: 某个任务执行失败了？
A: 会自动暂停，你可以选择重试或跳过

Q: 想并行执行多个任务？
A: 用 /admin:apply --parallel，会自动识别独立任务

Q: 回滚后代码能正常运行吗？
A: 选择性回滚时会确保代码处于可运行状态，
   有依赖关系的任务会提示一起回滚
```
